# 아이맘 안드로이드 앱(APK) 설치 안내

> **안드로이드 전용**이에요 (폰·태블릿 모두 가능). 아이폰·아이패드는 설치 대신 **웹 데모**를 이용해 주세요: https://ai-mom.expo.app
> 서비스 소개: https://ai-mom.expo.app/landing.html

---

## 1. APK 파일 받기

1. 안드로이드 폰(또는 태블릿)에서 아래 링크를 엽니다.
   - **APK 다운로드:** `제출 양식의 APK 링크` (약 170MB · 와이파이 권장)
2. 크롬에서 "이 파일은 기기에 해를 끼칠 수 있습니다"가 뜨면 **다운로드**를 누릅니다.
   - 아이맘은 Google Play에 올리지 않은 시연용 앱이라 나오는 일반 안내예요.

## 2. 설치하기

1. 다운로드가 끝나면 알림에서 **열기**를 누릅니다.
   - 알림이 사라졌다면 **내 파일 → 다운로드** 폴더에서 `.apk` 파일을 누릅니다.
2. "보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다"가 뜨면:
   - **설정** → **이 출처 허용**(켜기) → 뒤로 가기
   - 삼성 갤럭시: 설정 → 애플리케이션 → 특별한 접근 → **출처를 알 수 없는 앱 설치** → 크롬(또는 내 파일) → 허용
3. **설치**를 누릅니다.
4. "Play 프로텍트에서 앱 차단됨" 또는 "안전하지 않은 앱"이 뜨면:
   - **세부정보 더보기** → **무시하고 설치**(또는 **설치하기**)
5. 설치가 끝나면 **열기**를 누릅니다.

## 3. 처음 실행하기

앱을 열면 권한을 물어봐요. 아래처럼 허용해 주세요.

| 권한 | 쓰는 곳 |
|---|---|
| **마이크** | 부모 목소리 학습, 아이 말소리 듣기 |
| **카메라** | 입모양 수치 측정 (얼굴 영상은 저장하지 않아요) |

### 기기 2대 (부모 폰 + 아이 태블릿) — 권장

1. **부모 폰**: 앱 실행 → **부모 폰으로 쓰기** → **시작하기** → 아이디·비밀번호로 가입
2. 아이 소개 → 말투·호칭 → 아바타 꾸미기 → 문장 몇 개 읽기(목소리·입모양 학습) → PIN·동의
3. 마지막 화면에 **연결 코드**(6자리)가 나와요.
4. **아이 태블릿**: 앱 실행 → **아이 태블릿으로 쓰기** → 연결 코드 입력
5. 아바타가 먼저 말을 걸어요. **놀자 · 손 놀이 · 동화 듣기 · 엄마랑 이야기**를 눌러 보세요.
6. 부모 폰의 **리포트 · 피드백** 탭에서 오늘 반응과 내일 계획을 확인해요.

### 기기 1대로 보기

1. 부모로 가입한 뒤 **설정 → 이 기기를 아이 모드로 바꾸기**
2. 아이 화면 체험
3. 화면 위 **부모** 버튼을 **3초 꾹** 누르고 PIN을 넣으면 부모 화면으로 돌아와요.
4. 2일차(과자)를 바로 보려면: 피드백에서 내일 계획 낭독 → **설정 → 학습 이력 → 시연: 지금 다음 일차로 넘기기**

## 4. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "앱이 설치되지 않았습니다" | 예전에 받은 아이맘이 있으면 **먼저 삭제**한 뒤 다시 설치해 주세요. |
| 설치 버튼이 눌리지 않음 | 화면 필터 앱(블루라이트 등)을 잠시 끄고 다시 눌러 주세요. |
| "서버에 연결하지 못했어요" | 인터넷 연결을 확인해 주세요. 서버가 쉬고 있었다면 첫 응답에 30초쯤 걸릴 수 있어요. 첫 화면 아래 **서버** 주소가 `https://aimom-server.onrender.com` 인지도 확인해 주세요. |
| 아바타 목소리가 기계음 | 부모 목소리 학습 전이거나 잠시 연결이 느릴 때 기기 음성으로 말해요. 아바타 탭에서 문장을 더 읽어 주세요. |
| 진동이 안 느껴짐 | 기기 설정의 진동이 꺼져 있거나 진동이 없는 태블릿이에요. 대신 화면이 살짝 흔들려요. |
| 마이크·카메라를 거부했음 | 휴대폰 **설정 → 애플리케이션 → 아이맘 → 권한**에서 켜 주세요. |

## 5. 지우기

- 앱 삭제: 앱 아이콘을 길게 눌러 **삭제**
- 서버 기록 삭제가 필요하면 GitHub(https://github.com/InThon-Team19/ai-mom)로 알려 주세요. 심사 기간이 끝나면 서버 데이터는 모두 삭제해요.
