아이맘 부모 2D 아바타 통합 결과 (2026-11-01)

1. 반영 범위
엄마/아빠 각각 헤어 2종과 의상 2종, 총 8개 조합을 선택할 수 있습니다.
각 조합에 neutral/closed/open/wide/round/narrow 6개 완성형 이미지가 있습니다.
원본 생성 파일은 보존하고 입 영역만 코드로 정렬·합성했습니다.
입 크기 보정 3단계를 포함한 앱용 이미지는 144개(512×512 RGBA)입니다.
별도 눈깜박임·시선 오버레이 16개를 사용합니다. 런타임 입 레이어 합성은 없습니다.
기존 SVG 커스텀과 별도 3D 실험 파일은 보존했습니다.

2. 앱 연결
가입 아바타 화면과 부모 설정 화면에서 같은 커스텀 선택기를 사용합니다.
기존 프로필은 SVG 설정을 유지하며, 새 프로필은 일러스트 스타일로 시작합니다.
일러스트/SVG 전환 시 기존 숫자형 커스텀 필드를 보존합니다.
부모 설정 저장은 서버 완료를 기다리고 실패 시 재시도 안내를 표시합니다.
연결된 아이 기기는 다음 프로필 새로고침 시 선택을 받습니다(즉시 푸시 동기화 아님).
입모양 전환에는 Animated.Value와 ref를 사용하며 매 틱 React state를 갱신하지 않습니다.
활성 조합의 이미지 6장을 먼저 불러오며 크로스페이드 없이 전환합니다.
일러스트의 neutral/smile/praise는 같은 차분한 기본 표정을 사용합니다.
기존 SVG의 표정 기능은 그대로 남아 있습니다.

4. 미검증 및 립싱크 한계
사용자 요청에 따라 실제 화면 클릭, 기기 실행, 스피커 음성 재생은 검증하지 않았습니다.
실기기 FPS/메모리, 실제 운영 서버 연결과 아이 기기 반영도 미검증입니다.
가상 프레임 전환과 실제 TTS 타임스탬프 데이터 검증은 분리했습니다.
묶음 TTS 샘플의 실제 이벤트 시간표가 WAV 길이 안에 있는지는 자동 검사했습니다.
이는 부모 복제 음성 재생 검증이 아닙니다.
일반 TTS에 실제 Viseme 타임스탬프가 없으면 텍스트/오디오 기반 근사 방식입니다.
정확한 발음 동기화를 달성했다고 주장하지 않습니다.
